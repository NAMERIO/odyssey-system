##### 📖 SYSTEM & DEVELOPER MANUAL 
---

##### Prerequisites:
Download & install [node.js](https://nodejs.org/en/download), [pnpm](https://pnpm.io/), [uv](https://docs.astral.sh/uv/) & [Docker](https://docs.docker.com/get-started/)

##### Installation:
```sh
pnpm install:all
cp odyssey-config.example.hjson odyssey-config.hjson
pnpm db:start
pnpm dev
```

###### How to run it:
`pnpm dev` runs the server, client and desktop app together. `pnpm test` runs the tests and
`pnpm lint` fixes formatting.
